Modular monolith

Explicit layers. One atomic quiz workflow.

One Node.js process serves EJS pages, static assets, and JSON APIs. Routes expose policy, controllers coordinate requests, services own reusable workflows, and Mongoose models enforce persistence rules.

  • Server authoritative: correct answers never leave the start endpoint.
  • Transactional: score, XP, rewards, and session finalization commit together.
  • Role aware: learner ownership and administrator authorization remain explicit.

Known limitations

Clear boundaries for the current release candidate

These constraints are documented in the project and should be revisited before relevant production scale.

  • 01

    Single-process rate limits are not shared across application instances.

  • 02

    CSV reports are memory-buffered and intended for portfolio-scale data.

  • 03

    List pagination is offset-based and can slow on deep pages.

  • 04

    Daily completions are embedded in the daily challenge document.

  • 05

    SMTP and Cloudinary are optional and require external configuration.

  • 06

    Browser automation targets Chromium; broader browser and assistive-technology review remains future work.
