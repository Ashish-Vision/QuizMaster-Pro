# Screenshot guide

Capture the real local application with synthetic accounts and questions. Do not include personal email addresses, tokens, database identifiers, browser extensions, or credentials.

Recommended desktop size: **1440 × 900**. Recommended mobile size: **390 × 844**. Use PNG or optimized WebP and keep each image reasonably sized for GitHub.

## User captures

| Filename                            | Content                                             |
| ----------------------------------- | --------------------------------------------------- |
| `user/login-desktop.png`            | Login form and visual branding                      |
| `user/dashboard-desktop.png`        | Dashboard categories, progress, and daily challenge |
| `user/dashboard-mobile.png`         | Responsive dashboard                                |
| `user/quiz-desktop.png`             | Active quiz without revealing correct answers       |
| `user/result-desktop.png`           | Completed synthetic result                          |
| `user/leaderboard-desktop.png`      | Ranked synthetic users                              |
| `user/analytics-desktop.png`        | Populated performance charts                        |
| `user/achievements-desktop.png`     | Locked and unlocked achievements                    |
| `user/notifications-desktop.png`    | Synthetic notification list                         |
| `user/profile-settings-desktop.png` | Profile or settings without private values          |

## Architecture media

Store exported diagrams or a social-preview composition under `architecture/`. Prefer source-controlled Mermaid diagrams in Markdown when a separate image adds no value.

After adding real files, link only the best six to eight images from README. Verify dark-theme contrast and crop out irrelevant browser chrome.
